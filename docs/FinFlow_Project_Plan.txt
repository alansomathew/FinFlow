1. Executive Summary
FinFlow is a comprehensive, cross-platform personal finance application built with Flutter. It combines daily expense tracking, smart budgeting, loan & EMI management, investment portfolio tracking (SIP, Mutual Funds, Stocks), and AI-powered financial insights into a single, beautifully designed app.

The application is designed primarily for the Indian market with full support for UPI, bank SMS parsing, INR multi-currency, and India-specific investment instruments, while remaining globally usable.

4.2 SMS Parsing & Duplicate Detection
Bank transaction SMS messages follow semi-standard formats. FinFlow implements:
Regex-based parser library covering 30+ Indian bank formats (SBI, HDFC, ICICI, Axis, Kotak, etc.)
Extracts: amount, merchant/payee, transaction type (debit/credit), date, account last 4 digits, reference number
Duplicate detection using a composite key: amount + date (±2 min window) + account + reference number hash
If two messages arrive for the same transaction (common with UPI — one from bank, one from UPI app), system shows only ONE prompt with confidence score
User sees a bottom sheet on app open: 'New transaction detected — Add or Skip'
Batch review mode if multiple SMS arrived while app was closed

4.3 Security Model
AES-256 encryption for all locally stored financial data
SSL/TLS for all network traffic
Biometric authentication (Fingerprint / Face ID) as secondary lock
Optional 2FA via Firebase Auth
No plain-text storage of account numbers — stored as last-4-digit masked references
Auto-lock after configurable idle timeout (default: 2 minutes)

5. UX & Design Philosophy
5.1 Core Design Principles
One-Tap Entry: FAB always visible; expense logged in under 3 taps
Progressive Disclosure: Basic users see simple UI; Pro features elegantly revealed
50/30/20 Visual Language: Color-coded categories (Needs = Blue, Wants = Amber, Savings = Green)
Dark Mode First: Designed dark-mode-first, light mode as secondary
Celebration Moments: Animated confetti when goals are hit, budgets maintained

5.2 Navigation Structure
Bottom Nav Bar: Home | Transactions | Budget | Invest | Analytics
FAB (+): Persistent, opens quick-add sheet with amount-first entry
Swipe Gestures: Left-swipe to delete, right-swipe to edit on transaction list
Search: Global search across transactions, goals, accounts

5.3 Onboarding Flow
Step 1: Splash + Guest Mode option (try without login)
Step 2: Google Sign-In (one tap)
Step 3: Currency & region selection
Step 4: Add first bank account or card (optional, skippable)
Step 5: Set monthly income & first budget
Step 6: Enable SMS permission for auto-parsing (optional, skippable)
Step 7: Home dashboard with sample data overlay for first-time users

6. Budget Reset & Period Logic
Monthly budgets are a cornerstone feature. FinFlow handles resets with precision:

Budgets reset on the 1st of each month by default (configurable to any date, e.g., salary date)
Reset is automatic via Cloud Function scheduled trigger at midnight on the reset date
Previous month data is archived — never deleted — viewable in the Analytics > Monthly History tab
Users receive a 'Month Ended' summary notification with total spend, savings rate, and top category
Rollover option (Pro): Unspent budget in a category can optionally roll over to next month
Weekly budgets are also supported as a toggle — resets every Monday
Budget progress bar turns amber at 80%, red at 100% (push notification sent at both thresholds)
Envelope system: each category has a dedicated 'envelope' — overspend from one does NOT auto-borrow from another
